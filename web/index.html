What is it?

Epytodo is a to-do list app we developed as part of our project at Epitech.

It was developed primarily on the back end and then supplemented with front-end components.

Below you will find detailed information on how the project works.

How it Works

Here's how Epytodo makes managing your tasks easy and efficient.

Node.js & TypeScript

Epytodo is developed in Node.JS & TypeScript for the backend server, ensuring a robust and scalable foundation.

MySQL Storage

MySQL is used as the database management system, providing reliable data storage and retrieval.
